# FARMIS Goat Farm Manager

A single-file farm management app for a goat farm: herd register, health and medicines,
breeding, milk, weights, feed stock, transactions, tasks, daily reports and attendance,
with Admin, Supervisor and Worker roles.

Open `index.html` in a browser, or host it on GitHub Pages.
Data and accounts are stored in the browser (localStorage). Use the Backup tab to export and restore.
